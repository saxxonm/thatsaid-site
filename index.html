Least privilege, by default.

  • Read-only by design

    Agents can search and read transcripts. They can never edit, delete or start a recording.

  • A token per agent

    Every connection gets its own token, scoped read-only.

  • Revoke in one click

    Pull a token and that agent loses access immediately.

  • Access log

    See which agent read what, and when.

  • Encrypted cloud sync

    Cloud data is encrypted on our servers and isolated per account, behind email, password and 2FA.

  • Local when you want it

    On-device transcription, plus a Local-only mode on Mac that never syncs.
