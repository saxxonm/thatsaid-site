thatsaid MCP server

Endpoint: https://mcp.thatsaid.app · Streamable HTTP · listed in the MCP Registry as app.thatsaid/thatsaid

What it does

thatsaid records your meetings hands-free and transcribes them on your device. The MCP server lets the AI agents you choose (Claude, ChatGPT, Cursor and other MCP clients) search and read the transcripts, summaries and action items you sync with Cloud Sync. Every tool is read-only: agents can't change, delete or record anything, and audio never leaves your device.

Connect with OAuth (recommended)

In your MCP client, add a custom connector with the URL https://mcp.thatsaid.app. The client opens the thatsaid sign-in page. Sign in, finish two-step verification, and approve access. The client gets the read-only transcripts.read scope. You can see and revoke connected apps at any time under Agent Access in the thatsaid app.

Connect with a token

For clients without OAuth, open Agent Access in the thatsaid app and create a personal token (it starts with tsk_). Send it as a header:

Authorization: Bearer tsk_…

Treat the token like a password. Revoke it in Agent Access if it leaks. Requests are rate limited per token.

Tools

All tools are annotated readOnlyHint: true and destructiveHint: false.

  • get_settings · Get thatsaid settings. How your cloud copy is set up: retention, time zone, limits and the transcript file format.
  • list_transcripts · List transcripts. Conversations newest first, filtered by day, date range, words in the title, speakers or summary, or status.
  • search_transcripts · Search transcripts. Full-text search across every transcript, returning matching lines.
  • get_transcript · Get transcript. The full Markdown of one conversation: summary, action items and timestamped transcript, paged when long.
  • get_summary · Get summary. Only the metadata, summary and action items of one conversation.
  • list_speakers · List speakers. Named people who appear in your conversations.
  • get_profile · Get profile. Your time zone, retention, conversation count and when the current token expires.
  • list_fragments · List fragments. Retired and always empty. Kept so older clients keep working.

Each transcript is also available as a resource at thatsaid://transcript/{id}.

Privacy and logs

Each request is logged with the method, tool, timing and status so you can review it in Agent Access. Logs never contain tokens, arguments or transcript text. See the Privacy Policy and Terms of Service.
